## 栏目与来源的维护约定

用户确认的栏目方向和下面的 RSS 分组不同于旧引擎的五种执行模式。不要用栏目名称判断文章 skill，也不要调整 `profiles.json` 中旧五栏的顺序来达成改名；旧栏目涉及数据路径及发布类型兼容。

### 学术站

保留原有栏目；新采编方向为「项目合作」「课程资源」。项目合作须核验研究议题、实际找伙伴的需求、发起者和加入方式，不能将一般研究新闻、职位或资助公告自动判成结伴需求。当前社区 RSS 只是线索入口，未达到专门合作需求的完整覆盖。课程资源包含商业培训和开放培训，需逐条核验主办者、课程时间、价格及适合人群。Statistical Horizons 是商业科研统计培训提供者；其 RSS 并非全部课程日程。

本轮先在本地订阅库分组承接这两个方向；线上栏目、导航与发布分类尚未新增。它们需通过独立的分类扩展接入，不能冒用学者观察等旧栏目对外发布。

### 输入法站

- 输入法项目、中文方案、皮肤分别收录，键盘上游固件/工具和开团社区分开。
- Geekhack Group Buys 与 Interest Checks 分开；意向征集不等于正式开团，论坛回复时间也不等于开团日期。
- 灵犀公开 Release、main 提交流作为已公开进展来源；无私有令牌。提交、测试、平台验收、发布要分开描述。
- 年度开团日程：只记录核验过的实际年份、开始/结束日期和链接，不自动每年重复。
- 历史日历：依据原始史料的事件发生日，不用 RSS 发布日推断里程碑。CHM 等历史来源只是检索入口。
- 灵犀年度进度：已完成项应有发布/验收依据；计划项来自经维护者确认的路线图，不能从提交预测。

### 设计站

- 新闻媒体与设计机构/博物馆来源分组，历史条目需核对作品、作者及原始发生日期。
- 每年惯例包括节日、展会与奖项周期；时间不固定的展会每年重新核验，不复制上一年的月日。
- 图片在 RSS 中可见不代表可转载；保留作品署名、原文链接和授权记录。

### 学术海个人站

目标栏目：维护的键盘项目、输入法项目、网站服务项目，分享的开源工具项目、学术网站项目；前端无需日历。

RSS 中的 QMK、ZMK、Rime、Tauri 等归为“上游动态”，不能表述为作者本人维护的项目。灵犀单列自己的公开进展。其他本人项目需补确切仓库/项目地址后才增加专属动态源；不访问或暴露私有仓库凭证。

### 萌宠站

- 猫、狗分别组织，资讯与异宠分组；“每日一猫/狗”是编辑计划，不表示来源每天稳定供稿或图片自动获得授权。
- 异宠目前涵盖爬宠、兔、水族等线索，不宣称覆盖所有物种；个体诊疗不由百科模板生成。
- CFA 与 Westminster 提供赛事线索，具体赛程仍回主办方确认。
- 宠物节日、展览、比赛分别管理；比赛/展会跨年日期可能变化，只有有依据的固定节日才设置固定月日重复。

## 明确的覆盖缺口

1. 中国境内课题结伴需求与商业培训：大量信息在微信群/公众号、登录站点及邮件中，本轮没有将搜索页、登录页或未经核验的公共 RSSHub 地址加入。
2. 国内键盘开团与输入法商业产品：部分没有稳定公开 RSS；现有社区与仓库流无法等于“所有资讯”。
3. 设计展会、Interzoo/亚洲宠物展等官网：有公开日程不等于存在 RSS。本轮未验证到的入口仅列为人工核验来源。
4. 历史年表、个人规划与未来日程不能靠新闻订阅自动获得；需要人工原子化整理和来源审核。
5. 已剔除空 XML、HTML 页面、403/404、重复评论/子集流和多年停更的一般新闻源。维护型 GitHub 仓库即使很久未发布也可保留作版本/历史资料，不承诺活跃。
